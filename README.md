# Finca El Retiro

App web (PWA) de gestión de la finca El Retiro, Pradera (Valle).

- `index.html`: toda la app (interfaz, agentes de IA y conexión a Supabase).
- `sw.js`: modo sin conexión. Al publicar una versión nueva, cambiar `CACHE_VERSION`.
- `manifest.json` e íconos: instalación en el celular.

Se publica en Netlify desde la rama `main`: https://finca-el-retiro.netlify.app
